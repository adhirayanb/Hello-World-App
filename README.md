# Hello-World-App

A simple Java "Hello World" application.

## Project Structure

```
Hello-World-App/
├── src/              # Source code
├── bin/              # Compiled class files
├── HelloWorld.java   # Main Java file
├── README.md
└── .gitignore
```

## Compilation

Compile the Java file:

```bash
javac HelloWorld.java -d bin
```

Or compile from src to bin:

```bash
javac src/HelloWorld.java -d bin
```

## Running

Run the compiled program:

```bash
java -cp bin HelloWorld
```

## Requirements

- Java Development Kit (JDK) 8 or higher
